# Download checksums (SHA-256)

Fingerprints of the current release downloads (Nox 1.1). If a file you downloaded gives a different fingerprint, do not open it.

```
c556b472b2aae0b35e44cd913312deda1f623d566ca79937883ad183d42911f7  Nox-mac.zip
3844f8b91fa313a03be7d47125fa29de1c70a23a5391f1e256cfc3c8c691b3a5  Nox-windows.zip
0ff8d37d9bd18a2c60d2e09accbb0eb754a24e8fe79c33d4780691d5595da982  Nox.dmg
```

Check on Mac: `shasum -a 256 <file>`. Check on Windows: `certutil -hashfile <file> SHA256`.

Release: [v1.1](https://github.com/Solomon-69/Nox/releases/tag/v1.1) (Nox.dmg, Nox-mac.zip, Nox-windows.zip). A SHA256SUMS.txt file is attached to the release too.

The apps are not signed yet; see the "Unsigned apps" section of the README.

# Download checksums (SHA-256)

Fingerprints of the current release downloads. If a file you downloaded gives a different fingerprint, do not open it.

```
2d5c2ce5c9abd75e05b7ef01c69239f53cd76e032fe17ae16d4ecc38174775c8  Nox-mac.zip
8512c4b2defac25fffda87de9491837c233e5c96b0120eee135f79031a4d8337  Nox-windows.zip
b65b8912e82f709e157af754c0dbd30db923154e7c85c96ab53b92ba6087e13b  Nox.dmg
```

Check on Mac: `shasum -a 256 <file>`. Check on Windows: `certutil -hashfile <file> SHA256`.

Release: v1.0.0 (Nox.dmg, Nox-mac.zip, Nox-windows.zip).

Version 1.0.1 is the current version. Its downloads have not been published yet, so the fingerprints above belong to the last published build (1.0.0). New fingerprints are added here when 1.0.1 is released.

The apps are not signed yet; see the "Unsigned apps" section of the README.

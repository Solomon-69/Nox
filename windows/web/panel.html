Websites follow your PC
Add the Chrome/Edge extension once: Gmail and every site follow
  1. Click Add to Chrome or Add to Edge. Nox opens the extensions page and copies the folder location for you.
  2. Turn on Developer mode (top right in Chrome, left side in Edge).
  3. Click Load unpacked, press Ctrl+V in the folder box, then Select Folder.
Done once: after that, every site (Gmail too) turns dark with Windows and light again with it. Nothing is read or sent.
